# مارلوگل | نسخه نمایشی Next.js

به‌روزرسانی اسلایدر و سئو: سه اسلایدر محصول در خانه، صفحات دسته‌بندی، متادیتای مستقل، لینک محصول و Breadcrumb/WebSite schema اضافه شد؛ توضیح وضعیت ایندکس در `SEO.md` است. دمو همچنان noindex است.

**این ZIP نسخه مخصوص Vercel است. ابتدا `VERCEL.md` را بخوانید.** روی Vercel اتصال MongoDB و نوشتن بک‌اند غیرفعال‌اند و پنل/سفارش‌ها فقط در مرورگر شبیه‌سازی می‌شوند. توضیحات اتصال MongoDB زیر برای حالت opt-in محلی و شرح نسخه قبلی‌اند، نه نسخه آنلاین.

نسخه ۱.۲: فرم ساخت محصول با اطلاعات دلخواه و ویرایش اضافه شد. محصولات، موجودی بسته‌ها، سفارش‌های ساختگی، وضعیت‌ها و پیش‌نمایش پیامک در پروژه Next.js از MongoDB محلی خوانده و ذخیره می‌شوند. پیش‌نمایش ClickUp همچنان فقط localStorage دارد. صفحات `/products` و `/build-bouquet` مستقل‌اند؛ یک بسته داوودی + یک بسته رز = ۱۹ تا ۲۰ شاخه.

فروشگاه مستقل فارسی و راست‌چین با چیدمان واکنش‌گرا برای موبایل و دسکتاپ، تصاویر اختصاصی تولیدشده، کاتالوگ، علاقه‌مندی، سبد، سفارش نمونه، پیگیری و داشبورد عمومی نمایشی.

**این پروژه فروشگاه عملیاتی نیست. هیچ شماره تلفن، کد واقعی OTP، آدرس واقعی، اطلاعات کارت، کلید درگاه یا اطلاعات شخصی دریافت نمی‌کند. هیچ پیامکی ارسال نمی‌شود و هیچ پرداخت یا بازپرداختی انجام نمی‌شود. پنل مدیر بدون احراز هویت است و فقط برای دمو مناسب است.**

## اجرای سریع

Node.js نسخه 20.9 یا بالاتر، Docker Compose و اینترنت برای نصب بسته‌ها و تصویر MongoDB لازم‌اند. پنل صرفاً روی development محلی قابل نوشتن است.

```bash
npm install
cp .env.example .env.local
docker compose up -d --wait
npm run seed -- --yes
npm run dev
```

نشانی: `http://127.0.0.1:3000/admin`. فایل محیطی پیش‌فرض اتصال replica set محلی را آماده می‌کند. Docker دیتابیس را فقط روی loopback باز می‌کند. برای بررسی build:

```bash
npm run test
npm run build
npm start
```

از آخرین وصله امنیتی شاخه پایدار Next.js استفاده کنید. زمان تهیه پروژه، منبع رسمی نسخه 16.4 را معرفی کرده بود؛ نسخه‌ها در package.json به‌صورت بازه سازگار هستند و lockfile ساخته نشده است. پیش از انتشار، خروجی نصب و هشدارهای امنیتی را بررسی کنید: https://nextjs.org/blog

## MongoDB و بک‌اند محلی

نام دیتابیس باید به `_demo` ختم شود. MongoDB باید replica set باشد؛ compose این تنظیم را دارد. نوشتن نیازمند `LOCAL_DEMO_WRITES=true`، حالت development و درخواست same-origin از localhost است. در production همه نوشتن‌ها عمداً با 403 رد می‌شوند.

```bash
npm run seed -- --yes
```

seed فقط محصولات و بسته‌های گمشده را اضافه می‌کند و محصول موجود را بازنویسی نمی‌کند. ایندکس‌های یکتای slug، id و requestId ایجاد می‌شوند. هیچ کالکشنی حذف نمی‌شود.

کالکشن‌ها: `products`، `flower_packs`، `demo_orders`، `demo_messages` و `demo_events`. کاتالوگ عمومی خواندنی است. ایجاد و ویرایش محصول، موجودی بسته‌ها، ثبت سفارش ساختگی و تغییر وضعیت API دارند. محصولات و بسته‌ها با revision جلوی بازنویسی هم‌زمان را می‌گیرند. سفارش، کسر موجودی و پیام نمونه در یک transaction ثبت می‌شوند؛ لغو مجاز با ساعت سرور کنترل و موجودی تنها یک‌بار برگردانده می‌شود. نام، قیمت و تعداد شاخه از سرور محاسبه می‌شوند؛ مبلغ مرورگر مورد اعتماد نیست.

**در ZIP جدید، فقط سبد و علاقه‌مندی در localStorage هستند؛ محصولات، موجودی و سفارش ساختگی در دیتابیس‌اند.** در پیش‌نمایش ClickUp تمامی داده‌ها همچنان محلی‌اند. هیچ شماره، نشانی واقعی یا رمز ورود جمع‌آوری نمی‌شود. فرم محصول از گالری عکس نمونه استفاده می‌کند؛ آپلود عکس ساخته نشده است.

بدون MongoDB یا با خطای اتصال، ذخیره خطا می‌دهد و موفقیت جعلی اعلام نمی‌شود. اگر URI اصلاً تنظیم نشده باشد، کاتالوگ نمونه فقط برای نمایش ظاهر می‌شود؛ نوشتن کار نمی‌کند. برای اتصال غیر Docker، URI یک replica set سازگار را تنظیم کنید. اطلاعات اتصال هرگز به کلاینت فرستاده نمی‌شوند.

فهرست APIها و محدودیت‌های این نسخه در `BACKEND.md` آمده است. مدارک `UPDATE-1.1.md` و `HANDOFF.md` شرح تاریخی نسخه قبل‌اند؛ وضعیت فعلی را از این README و BACKEND بخوانید.

## مسیر امتحان‌کردن

1. یک گل را به سبد اضافه کنید.
2. روز تحویل را انتخاب کنید؛ پیش‌فرض فردا و محدوده تا روز هفتم آینده است.
3. کرج را انتخاب کنید تا محدودیت تهران را ببینید، سپس به تهران برگردید.
4. «ورود نمونه» را بزنید، سپس سبد را دوباره باز و پرداخت موفق نمایشی را انتخاب کنید.
5. در پیگیری، سفارش و پیش‌نمایش پیامک خرید را ببینید.
6. داشبورد مدیریت را باز کنید، آماده‌سازی و «آماده ارسال + پیامک» را امتحان کنید.
7. بازه تقریبی را تغییر دهید و پیش‌نمایش پیامک را ببینید.
8. پیش از مهلت مجاز سفارش را لغو کنید، یا پس از آماده‌شدن تحویل را ثبت کنید.

قیمت‌ها تومان هستند. هزینه ارسال ۱۵۰ هزار تومان و رایگان از ۳ میلیون تومان صرفاً **سیاست نمونه انتخاب‌شده برای دمو** است، نه شرط اعلام‌شده مالک فروشگاه.

## قانون زمان

روز تحویل به وقت `Asia/Tehran` و با نمایش تقویم فارسی محاسبه می‌شود. تاریخ ذخیره‌شده میلادی ISO است. لغو تا ساعت ۲۲:۰۰:۰۰ شب قبل از روز تحویل مجاز است؛ از یک میلی‌ثانیه بعد غیرمجاز است. آماده‌شدن سفارش مهلت را حذف نمی‌کند، اما سفارش لغوشده یا تحویل‌شده دوباره لغو نمی‌شود.

در پیش‌نمایش، ساعت مرورگر مرجع است؛ در بک‌اند جدید، تاریخ و مهلت لغو دوباره با ساعت سرور کنترل می‌شوند. مالکیت واقعی سفارش و احراز هویت مشتری/مدیر در این پروژه ساخته نشده؛ همه سفارش‌ها متعلق به «مشتری نمونه» مشترک‌اند.

## سئو و محدودیت ادعا

App Router، رندر سمت سرور کاتالوگ، صفحات مستقل محصول، عنوان و توضیح متادیتا، canonical، Open Graph، زبان فارسی، alt تصاویر، robots و فایل sitemap وجود دارند. صفحات نمونه:

- `/products/pink-garden`
- `/products/red-roses`
- `/products/white-box`
- `/products/white-tulips`
- `/products/sunshine`

به عمد کل دمو `noindex, nofollow` است، robots دسترسی خزنده را می‌بندد و sitemap خالی است. هیچ رتبه‌بندی، نظر مشتری یا مجوز جعلی اضافه نشده است. Schema محصول بدون Offer منتشر می‌شود چون قیمت‌ها نمونه‌اند. برای نسخه واقعی، دامنه، محصولات، موجودی، اطلاعات حقوقی و عکس‌های واقعی را تأیید کنید؛ سپس سیاست ایندکس، نقشه سایت و داده ساختاریافته واقعی را فعال کنید. رتبه اول گوگل قابل تضمین نیست.

## تصاویر و فونت

عکس‌ها برای این دمو با هوش مصنوعی ساخته و به WebP تبدیل شده‌اند؛ عکس کالای واقعی نیستند. لوگوی وهو و نظرات مشتریان آن کپی نشده‌اند. فونت Vazirmatn از Google Fonts و فونت جایگزین Tahoma است. برای استقرار بدون وابستگی بیرونی، فونت را با مجوز مناسب self-host کنید.

## وضعیت تست

رابط مشترک React در پیش‌نمایش ابزار با تست مرورگر بررسی شده است. تست مستقل قوانین تاریخ با Node.js اجرا شده است. به علت نبود دسترسی اینترنت در محیط ساخت، نصب وابستگی‌ها و build کامل **بسته Next.js** انجام نشده؛ این کار باید روی سیستم شما انجام شود. هیچ ارتباط واقعی با MongoDB، sms.ir یا زرین‌پال در محیط ساخت آزمایش نشده است.

تست integration برای اجرای روی Next.js و MongoDB داخل ZIP است (روی دیتابیس دمو، نمونه‌های تازه ایجاد می‌کند):

```bash
npx playwright install chromium
# Linux/macOS:
TEST_MONGO=1 npm run test:e2e
# PowerShell: $env:TEST_MONGO="1"; npm run test:e2e
```

تست‌های پیش‌نمایش مشترک React در `tests/preview` نگهداری می‌شوند و بخشی از تست integration Next.js نیستند. در محیط ساخت تست مرورگر رابط و تست‌های مستقل اعتبارسنجی/تاریخ/ترکیب اجرا می‌شوند؛ **اتصال واقعی MongoDB و build کامل Next.js در محیط بدون اینترنت اجرا نشده‌اند.**

برای وضعیت فعلی بک‌اند و مرز نسخه نمایشی، `BACKEND.md` را بخوانید؛ `HANDOFF.md` سند تاریخی الزامات نسخه عملیاتی است.
